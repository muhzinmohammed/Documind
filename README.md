# DocuMind

**An AI-powered document assistant that lets you chat with your PDFs.**

DocuMind is an AI-powered PDF question-answering application built using React, FastAPI, Ollama, and ChromaDB.

It allows users to upload PDF documents and interact with their contents through a conversational interface.

Using Retrieval-Augmented Generation (RAG), DocuMind retrieves relevant information from uploaded documents and generates context-aware answers using locally hosted Large Language Models (LLMs).

### Key Features

- Upload and process PDF documents.
- Ask questions about document contents.
- Generate context-aware answers using AI.
- Retrieve relevant information through semantic search.
- View source references with page numbers.
- Run AI models locally without paid API subscriptions.

### Built With

React · FastAPI · Python · Ollama · ChromaDB · Sentence Transformers

### Project Goal

The goal of DocuMind is to make document interaction easier by combining semantic search and generative AI into a simple conversational interface.
